# 素材カード：iPhoneショートカットでレシートをObsidianに登録する

記事「Obsidianにレシートを登録する方法」用の素材カード。
スクリーンショット14枚（ショートカット4つ分）から読み取れた事実をまとめ、読み取れなかった点は「❓要確認」としている。

## カード0：全体像

| 項目 | 内容 |
|---|---|
| 仕組みの名前 | **mrec**（ショートカット名・ファイル名・保存先フォルダ名の共通プレフィックス） |
| 使うもの | iPhone「ショートカット」アプリ / ChatGPT（「ChatGPTを使用」アクション） / Obsidian |
| 保存先 | フォルダ `01_mrec`（Obsidian保管庫内のフォルダと思われる ❓要確認） |

| ショートカット数 | 4つ（入力方法ごとに分けている） |

### 4つのショートカット一覧

| # | ショートカット名 | 入力 | AI処理 | アイコン | 画像 |
|---|---|---|---|---|---|
| 1 | mrecレシート処理_撮影 | カメラで撮影 → OCR | ChatGPT | カメラ | 01〜04 |

### 共通の処理フロー（#1〜#3）

```
ファイル名を作る → 入力を得る → テキスト化 → プロンプトに埋め込む → ChatGPTで整形 → 01_mrec に .md で保存
```

## カード1：mrecレシート処理_撮影

- 説明カード表示：「写真を撮る / 画像から文字を読み取る / ChatGPTで分析する / メモを保存する」
- 画像：`images/01_satsuei_overview.png` 〜 `04_satsuei_save.png`

**アクション構成**

1. **テキスト**：`mrec_` + `現在の日付` + `時間`
2. **変数に追加**：テキスト → 変数 `name`
3. **写真を撮る**：1枚の写真を「背面」カメラで撮る
4. **テキストを抽出**：写真からテキストを抽出（iOS標準のOCR）
5. **テキスト**：`抽出されたテキスト`
6. **テキスト**（プロンプト本文）→ カード5参照。`text:` の下に `抽出されたテキスト` を差し込み
7. **ChatGPTを使用**：入力＝直前のテキスト（プロンプト）
8. **ファイルに追加**：`応答` を `01_mrec` へ追加
   - ファイルパス：`name` + `.md`
   - 新しい行を作成：オン

メモ：手順5の「テキスト」アクションは中身が `抽出されたテキスト` だけ。プロンプト側は抽出テキストを直接参照しているので、なくても動く可能性あり（記事で触れるか検討）。

## カード3：mrecレシート処理_テキスト

- 説明カード表示：「ChatGPTでレシートを分析し、メモボックスに記録する」
- 画像：`images/05_text_overview.png` 〜 `08_text_save.png`

**アクション構成**

1. **テキスト**：`mrec_` + `現在の日付` + `時間`
2. **変数に追加**：テキスト → `name`
3. **テキスト**：`毎回尋ねる`（実行時に入力ダイアログ）
4. **テキスト**（プロンプト本文）：`text:` の下に手順3の `テキスト` を差し込み
5. **ChatGPTを使用** → 6. **応答を `01_mrec` へ追加**（`name.md`、新しい行を作成オン）

- 用途の候補 ❓要確認：
  - ネット通販の購入明細メールを貼り付ける
  - 写真アプリの「テキスト認識表示」でコピーした文字を貼る
  - 口頭メモ／音声入力でざっくり入力

   ---
   ```
   title: <タイトル>
   ...（以降はスクショ外）
   ```
   → YAMLフロントマター付きのMarkdownを組み立てている

## カード5：ChatGPTに渡すプロンプト（#1〜#3共通）

スクショで読み取れた部分：

```markdown
# レシートテキスト
text:
{抽出されたテキスト or 入力テキスト}

# 目的
・画像のテキストからmdファイルを作成する
・次の指示1〜3を順番に実行して下さい

# 指示1【必要情報を抽出】
［text］の中から合計金額と店舗名、購入日、各商品とその商品の値段を抽出して下さい
sum: 合計金額（桁区切りなし）
store: 店舗名
date: 購入日（YYYY/MM/DD）
month: 購入日（YYYY-MM）   ← 下半分が切れていて推定 ❓要確認
...
```

- ❓要確認：指示1の続き、**指示2・指示3の全文**、出力フォーマット指定（フロントマター例など）
- ポイント（記事で強調できそう）
  - 見出しで「入力データ / 目的 / 指示」を分ける構造化プロンプト
  - `sum` は**桁区切りなし** → Dataview等で数値として集計できる
  - `date` と別に `month` を持たせる → 月別集計が楽
  - 「順番に実行」と明示してステップ処理させている

## カード6：ファイル名と保存の設計

- ファイル名：`mrec_` + 現在の日付 + 時間 → 同じ日に複数枚でも重複しない
  - ❓要確認：日付・時間の書式設定（例 `20261113` + `1050` など）
- 「ファイルに追加」アクションを使用 → ファイルがなければ新規作成、あれば追記
- 保存先 `01_mrec`：❓要確認
  - Obsidian保管庫の場所（iCloud Drive / 「このiPhone内」）
  - 「ファイルに追加」でのフォルダ指定方法（アクセス許可の付与手順）
- 番号付きフォルダ名（`01_`）＝ 保管庫内で上位に表示させる工夫？ ❓要確認
